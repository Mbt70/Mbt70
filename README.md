### Re:Action

**팀장 · 프로젝트 총괄·일정 관리·백엔드 기능 개발 · 한이음 드림업** · 2026년 4월–현재

현재 프로토타입 개발·검증 단계입니다. 실제 사용자 행동의 개선 효과는 별도 검증이 필요합니다.
