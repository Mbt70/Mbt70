## How I work / 작업 방식

I like work that leaves evidence.

1. Define the problem clearly / 문제를 먼저 정의합니다
2. Identify users, variables, and constraints / 사용자·변수·제약조건을 봅니다
3. Build the smallest useful artifact / 가장 작은 산출물로 만듭니다
4. Verify with tests, screenshots, or decision logs / 테스트·스크린샷·결정로그로 검증합니다
5. Turn the result into a case study / 결과를 케이스 스터디로 남깁니다
